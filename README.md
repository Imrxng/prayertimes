# Gebedstijden 2026

Een visueel vernieuwde, responsieve website voor de EMB-gebedskalender 2026.

## Starten

Open `index.html` rechtstreeks in de browser, of gebruik een lokale server:

```bash
python3 -m http.server 8000
```

Open daarna `http://localhost:8000`.

## Toegevoegd

- Automatisch de huidige maand openen
- Maandkeuze met vorige/volgende knoppen
- Snelle maandnavigatie
- Volledig-schermweergave
- Downloadknop per maand
- Deelbare URL via `?month=7`
- Toetsenbordnavigatie met pijltjestoetsen
- Responsieve mobiele vormgeving
- Betere toegankelijkheid en foutafhandeling
